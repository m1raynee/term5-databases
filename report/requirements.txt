Формат отчёта по лабораторным работам
1. Цель работы
Кратко сформулировать цель выполняемой лабораторной работы исходя из её темы.
2. Ход выполнения работы
Выполнение необходимо оформить последовательно по упражнениям и пунктам методических указаний.
Для каждого пункта необходимо привести:
- номер упражнения и пункта;
- SQL-запрос, команду PostgreSQL или команду используемой утилиты;
- результат выполнения;
- при необходимости, краткое пояснение полученного результата.
Не требуется переписывать полную формулировку задания из методических указаний, достаточно указать номер пункта и показать его выполнение.
3. Выводы по заданиям
Для пунктов, в которых в методических указаниях требуется сравнить результаты, объяснить поведение СУБД или сделать вывод, необходимо обязательно привести соответствующее объяснение.
Например, недостаточно только показать ошибку ограничения FOREIGN KEY, CHECK, UNIQUE или конфликт транзакций — необходимо объяснить, почему PostgreSQL повёл себя таким образом.
4. Общий вывод
В конце отчёта кратко описать, какие возможности PostgreSQL были изучены в ходе лабораторной работы и какие практические результаты были получены.
 
Примечания:
1. SQL-код должен быть представлен текстом, а не только на скриншотах.
2. Скриншоты допускается использовать для подтверждения результатов выполнения запросов, ошибок, работы транзакций, утилит командной строки и других действий, которые целесообразно показать визуально. При этом большое количество однотипных скриншотов не требуется.
3. Главное требование к отчёту: по нему должно быть возможно проверить выполнение каждого пункта лабораторной работы и понять полученный результат.
